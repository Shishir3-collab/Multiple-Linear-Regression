# Multiple-Linear-Regression

Multiple Linear Regression

* Loaded and cleaned the economic index dataset.
* Explored the data using correlation, scatter plots, and pair plots.
* Selected interest_rate and unemployment_rate as features and index_price as the target.
* Split the data into training and testing sets.
* Standardized the features using StandardScaler.
* Trained a multiple linear regression model.
* Used 5-fold cross-validation and calculated MSE/RMSE.
* Evaluated predictions using MSE, RMSE, MAE, and R².
* Analyzed residuals using plots.
* Used statsmodels OLS to examine coefficients, p-values, R², and other statistical measures.
